# Python Power-Up (Cozmek)

Static website: open `index.html`, or publish with GitHub Pages (Settings > Pages > Deploy from branch > `/ (root)`).

Files: `index.html`, `style.css`, `script.js`, `logo.png`, `logo-white.png`.

Student results are saved in each browser's localStorage; the teacher dashboard (link at the bottom of the welcome screen) shows results stored in that browser and can export CSV.
